# קישורי WhatsApp לדמו ולטרום

## קישור wa.me (שיחה ישירה איתי)

תבנית: `https://wa.me/<מספר בלי + ובלי אפסים מובילים>?text=<טקסט מקודד>`

```
https://wa.me/972500000000?text=%D7%94%D7%99%D7%99%2C%20%D7%90%D7%A9%D7%9E%D7%97%20%D7%9C%D7%A8%D7%90%D7%95%D7%AA%20%D7%90%D7%AA%20%D7%94%D7%93%D7%9E%D7%95
```

(החליפו `972500000000` במספר שלכם. הטקסט המקודד: "היי, אשמח לראות את הדמו")

## קישור הדמו החי

הדמו של ולטרום נבנה ל-`demo/sites/veltrum/` (סטטי, ניתן לאירוח בכל מקום).
לאחר אירוח — עדכנו את `DEMO_URL` בקובץ `.env`; זה הקישור שנשלח לפרוספקטים
דרך `npm run send-demo`.

הרצה מקומית: `npm run demo veltrum` → http://localhost:3000

## QR

`assets/qr-veltrum.png` — קוד QR שמצביע על אותו קישור, להדגמות פנים-אל-פנים.
(אם הקובץ חסר — צרו מחדש מכל מחולל QR עם ה-DEMO_URL העדכני.)
